# ivarbrandt's Kodi Repository

Kodi addon repository for Altus, Nimbus, and other projects by Ivar Brandt.

## Installation

1. In Kodi, go to **Settings > File Manager > Add Source**
2. Enter: `https://ivarbrandt.github.io/`
3. Go to **Add-ons > Install from zip file** and select the source you just added
4. Install `repository.ivarbrandt`
5. Go to **Install from repository > ivarbrandt's Repository** and install addons
